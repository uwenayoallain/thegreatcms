# Astro example

[![AI assisted](https://img.shields.io/badge/AI%20assisted-yes-8a63d2)](https://github.com/uwenayoallain/thegreatcms#ai-assistance "Built with an AI coding assistant and reviewed by a human")

The smallest honest demonstration of a GreatCMS site: one managed hero, one
managed block list, one Markdown collection, one region nobody has ever edited,
and a contact form that posts to the studio.

- `.cms/schema.yaml` lists what may be edited. Every other line of markup in
  this folder is ordinary Astro the studio never sees.
- `content/cms/*.json` is what the studio writes. `about.intro` has no file on
  purpose: the about page renders the `default:` values from the schema, which
  is what every page does before the CMS has ever run.
- `content/blog/*.md` is a collection, stored as the Markdown with frontmatter
  that every static site generator already expects.
- `src/cms.d.ts` is generated by `greatcms types`, so a typo in a region id or
  a field name is a compile error. `pnpm typecheck` fails if it drifts from the
  schema.
- `src/components/Feature.astro` decides what the schema's `icon` select looks
  like. The CMS stores `git`, `bolt`, or `lock`; the site owns the drawing.
- The pages read like a real site. Which parts the studio edits is told once,
  in the footer's "How this site is built".
- Every link points at the address its page is built at, and speculation rules
  let the browser prerender the next page as the pointer settles on a link.
  They are data the browser reads, not a script, so no page ships JavaScript.

From the repository root:

```sh
pnpm --filter @greatcms/example-site-astro dev    # http://localhost:4321
pnpm --filter @greatcms/example-site-astro test   # axe, no-script, weight, contrast
```

Connect this folder as a site in the studio, give it `http://localhost:4321`
as the dev server, and edits show up here as you type. Set `PUBLIC_CMS_URL`
and `PUBLIC_CMS_SITE_ID` to point the contact form at your studio.

The built site contains no `<script>` tag and weighs a few dozen kilobytes
across five pages. The tests assert both.
